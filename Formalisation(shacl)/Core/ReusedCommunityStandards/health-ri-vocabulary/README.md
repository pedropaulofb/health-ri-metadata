# Pinned Health-RI vocabulary reference

Unmodified normative vocabulary v0.4.1 and non-normative validation shapes copied
from [the source repository](https://github.com/pedropaulofb/health-ri-metadata-vocabulary/tree/0a06931f250954443edd62d930547bf02bd77711)
at commit `0a06931f250954443edd62d930547bf02bd77711`. License: CC BY 4.0; attribution is retained in the Turtle files.
`scripts/validate_hri.py` adapts that commit's `scripts/validate.py` only to the local shapes path.

These files are not imported into core validation. Vocabulary inference must not
supply the anatomical evidence that the optional validator is meant to check.
Review a new source version deliberately; do not download mutable latest files in CI.
